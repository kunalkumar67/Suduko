# Flask Sudoku

A simple Flask-based Sudoku web application.

## Features

- Generate Sudoku puzzles
- Easy, Medium, and Hard difficulty levels
- Hint system
- Check solution
- Dark mode
- Timer
- Top 10 Leaderboard (Local Storage)
- Responsive UI
- Automated tests using pytest

## Installation

```bash
python -m pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```

## Run Tests

```bash
python -m pytest
```

Expected output:

```
21 passed
```
