# Sudoku - Web Application

A modern Flask-based Sudoku puzzle solver and game platform with an intuitive web interface.

## ✨ Features

- **Game Modes**: Easy, Medium, and Hard difficulty levels
- **Smart Gameplay**: Real-time hint system & solution validation
- **UI/UX**: Dark mode support & fully responsive design
- **Engagement**: In-game timer & local leaderboard (Top 10)
- **Quality**: Comprehensive pytest test suite

---

## 🚀 Getting Started

### Installation
```bash
python -m pip install -r requirements.txt
```

### Run Application
```bash
python app.py
```
Then open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser.
